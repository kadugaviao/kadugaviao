## 🛠️ What I'm building

**[Computer Vision Presence](https://github.com/kadugaviao/computer_vision_class_presence)**
Face-recognition attendance: the classroom camera recognizes enrolled students and marks them present live
on the teacher's panel. A from-scratch rewrite of CAMAMF, the attendance system I worked on that runs in
production at my university. Every runtime choice is benchmarked (ONNX Runtime vs OpenVINO, CPU vs Intel iGPU,
FP32/FP16/INT8), and privacy follows LGPD: consent, encrypted embeddings, real deletion.
`Java 21` `Spring Boot` `React` `Python` `OpenVINO` `Redis Streams` `PostgreSQL` `Docker`

**[Art Identifier](https://github.com/kadugaviao/art_identifier_amf)**
A prototype for the AMF museum: point your phone at an artwork and it recognizes the piece in AR and tells
its story with narrated audio. Runs with a single `docker compose up`, including a public HTTPS tunnel and QR code.
`Spring Boot` `PostgreSQL` `A-Frame` `MindAR` `Piper TTS` `Docker`

**[Spring Claude Kit](https://github.com/kadugaviao/claude-spring-agents)**
Claude Code customization for Spring Boot projects: a skill, four subagents (test writer, reviewer,
migrations, build runner) and Python hooks that lock down what each agent is allowed to edit and run.
`Claude Code` `Python` `Bash`

**[Owlbear Rodeo Handouts](https://github.com/kadugaviao/handouts_owlbear_extension)**
Extension for the Owlbear Rodeo virtual tabletop that syncs images and notes to players in real time.
`React` `TypeScript` `Vitest`
